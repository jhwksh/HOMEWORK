# 🦈 부캉이 집에 가자

길을 잃고 한 달째 동해에 머물고 있는 상어 **부캉이**를 하얀 바닷길을 따라 집까지 데려다주는 게임이에요.
가는 길에 쓰레기, 그물, 기름, 뜨거운 바닷물 같은 환경 문제를 만나면서 바다 생태계를 생각해 보게 만들었어요.

👉 [게임 열기](../bukang-game/index.html)

## 만들면서 배운 점 (아직 미숙한 점)

AI(Claude)와 같이 만들었는데, 처음에 두 번 정도 내가 원하는 것과 다른 게 나왔어요.

1. **첫 번째**: "게임 만들자"라고만 하니까 AI가 머리스타일 게임을 마음대로 만들었어요.
2. **두 번째**: 내가 생각한 장면(누가, 무엇을, 왜)을 처음부터 잘 설명하지 못했어요.

내가 아직 부족한 점은 **원하는 것을 처음부터 구체적으로 설명하는 것**이에요.
다음에는 이렇게 하려고 해요.

- 만들기 전에 AI와 먼저 의논하고, 정리된 내용을 확인한 다음 만들기
- 주인공, 목표, 장애물, 재미 요소, 전하고 싶은 메시지를 먼저 말하기
- 짧게 물어보고 짧게 답해 달라고 하기 (토큰 아끼기)
